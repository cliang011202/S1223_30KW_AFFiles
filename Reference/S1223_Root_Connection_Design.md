## 一、连接方案概述

| 参数 | 值 | 依据 |
|---|---|---|
| 连接类型 | **预埋螺栓套 T-bolt** (WEH 图 7.37b) | WEH §7.1.17 |
| 叶片根径 | Φ262 mm (圆柱段) | 与轮毂 Φ262 匹配 |
| 螺栓规格 | M16×1.5, ISO 898-1 10.9 级 | 离心力 43.7 kN ÷ 12 ≈ 3.6 kN/颗 |
| 数量 / 布置 | **12 颗**，均布 @ PCD=210mm | 叶片根径 − 2×26mm 边距 |
| 预紧力 | **100 ±5 kN** (70% of 10.9 级 M16 proof load) | WEH §7.1.17 "pre-loaded to reduce fatigue loading" |
| 螺栓套 | 钢质 Φ22×80mm, 外螺纹 M22 + 带肋圆柱面, 内螺纹 M16 | 王同光 §4.8.2 表 4-23, 4-31 |
| 端面形式 | **B 形式** — 螺栓套凸出端面，与法兰连接 | 王同光 §15 表 15-1 |
| 电偶隔离 | **GF-VEIL 表面毡 0.1mm** 铺设在 CFRP 与钢螺栓套之间 (r<0.3m) | 全碳方案特殊要求 |

## 三、螺栓套几何

### 3.1 外形尺寸

```
        螺栓套 (钢质, 材质 C45E / 42CrMo4)
        
        展向剖面:
        
        ┌──┐                        ┌──┐
        │  │←── M22 外螺纹 ───→│  │
        │  │   (长度 25mm)       │  │
        │  ├──────────────────────┤  │
        │  │                      │  │
        │  │   带肋圆柱面         │  │
        │  │   (长度 55mm)        │  │  Φ22mm
        │  │                      │  │
        │  ├──────────────────────┤  │
        │  │← M16 内螺纹         │  │
        │  │   (深度 45mm)        │  │
        └──┘                      └──┘
        │←──────── 80mm ────────→│
        
        肋形剖面 (放大):
        
            ┌─┐  ┌─┐  ┌─┐  ┌─┐     ← 肋高 0.8mm
        ────┘ │──┘ │──┘ │──┘ │───     肋距 4.0mm
              └──┘  └──┘  └──┘
```

| 参数 | 值 | 公差 | 依据 |
|---|---|---|---|
| 总长 L | 80 mm | ±0.5 | 叶根厚度 + 余量 |
| 外径 D | 22 mm | −0.1/+0 | — |
| 外螺纹 | M22×1.5 | 6g | 长度 25mm (外伸入法兰) |
| 内螺纹 | M16×1.5 | 6H | 深度 45mm (螺柱旋入) |
| 肋高 | 0.8 mm | ±0.1 | 王同光 表 4-31 B 形式 |
| 肋距 | 4.0 mm | ±0.2 | 增强与 CFRP 的机械咬合 |
| 肋形 | 梯形 (60° 夹角) | — | 避免应力集中 |
| 材料 | C45E (1.1191) 或 42CrMo4 (1.7225) | — | 调质 HRC 28–32 |
| 表面处理 | 镀锌 (电偶隔离) + 外表面喷砂 | — | Sa 2.5 级清洁度 |

> **依据**: 王同光 §4.8.2 表 4-23「内螺纹构型 B — 易加工，连接强度高」; 表 4-31「B 形式 — 填充玻纤三角条，剪切强度高，疲劳性能好」。
> 
> 全碳方案中，螺栓套周围的 "玻纤三角条" 改为 **全碳 UD 纱束填充**，与 CFRP 叶根材料相容。

### 3.2 螺栓套周围填充

              CFRP 叶根铺层

           │    ┌───────┐    │

## 四、叶根铺层序列 (r = 0 → 0.35m)

```
[从外到内 — 圆柱段全周长]
─────────────────────────────────────────────
L1:  CF-BX / ±45° / 1 × 0.25mm   (蒙皮外层)
L2:  CF-BX / ±45° / 1 × 0.25mm   (蒙皮内层)
L3:  CF-UD / 0° / N 层            (叶根主铺层, 渐进增厚)
     ...
R1:  CF-TX / ±45°&0° / 4 × 0.50mm  (叶根加强层, r=0→0.30m)
R_ISO: GF-VEIL / 0° / 1 × 0.10mm   (电偶隔离毡, r<0.30m)
─────────────────────────────────────────────
     总厚 @ r=0: ~12mm (含加强层)
```

> 叶根总厚度需容纳 Φ22mm 螺栓套。螺栓套周围最小 CFRP 包裹厚度 ≥ 3mm（避免拉拔失效）。

## 五、预紧力施加

### 5.1 预紧力

| 参数 | 值 | 说明 |
|---|---|---|
| 目标预紧力 F_p | 100 kN | M16 10.9 级 proof load 70% (M16 proof ≈ 143 kN) |
| 拧紧方法 | 扭矩法 | 使用校准扭矩扳手 |
| 润滑条件 | MoS₂ 润滑脂 | μ ≈ 0.12 (螺纹 + 支承面) |
| 扭矩 | 240 ±10 N·m | T = K·F_p·d, K≈0.15 (MoS₂+钢/钢) |
| 扭矩系数 K 验证 | 每批次 5 颗标定 | ISO 16047 |

### 5.2 拧紧顺序

```
三阶段对角交叉法:

阶段 1 (33% F_p ≈ 33 kN, T≈80 N·m):
    B01 → B07 → B04 → B10 → B02 → B08 → B05 → B11 → B03 → B09 → B06 → B12

阶段 2 (66% F_p ≈ 66 kN, T≈160 N·m):
    同上顺序

阶段 3 (100% F_p ≈ 100 kN, T≈240 N·m):
    同上顺序
    
最终检查: 顺时针对所有螺栓确认扭矩 (T=240 ±10 N·m)
```

> **依据**: WEH §7.1.17 "The stud is pre-loaded to reduce fatigue loading"。三阶段施加 + 对角交叉顺序确保法兰面均匀贴合。

## 六、拉拔测试要求

### 6.1 测试矩阵

| 测试类型 | 试样数 | 载荷 | 验收准则 | 依据 |
|---|---|---|---|---|
| **静态拉拔** | 3 颗 | 拉至失效或 ≥1.5×F_p=150 kN | 失效发生在 CFRP 外部 (非螺栓套/CFRP 界面)；平均失效载荷 ≥1.3×F_p | WEH §7.1.17 |
| **疲劳** | 3 颗 | R=0.1, F_max=0.6×F_p=60 kN, N=10⁶ | 残余强度 ≥95% 静态强度；无可见裂纹 | WEH §7.1.17 "survived for approximately 10⁶ cycles" |
| **预紧力松弛** | 3 颗 | 100 kN → 静置 24h | 残余预紧力 ≥85% (85 kN) | ISO 16130 |

## 九、风险提示

| 风险 | 发生概率 | 严重度 | 缓解措施 |
|---|---|---|---|
| 碳-钢电偶腐蚀 (全碳特有) | 中 | 高 | GF-VEIL 隔离毡 + 螺栓套镀锌 |
| 螺栓套拉拔失效 (CFRP vs GFRP 界面不同) | 低 | 极高 | 静态拉拔测试 (6.1 节) |
| 预紧力松弛 (CFRP 蠕变 vs GFRP) | 中 | 中 | 预紧力松弛测试 (6.1 节); 超拧 5% 补偿 |
| 螺栓套与 CFRP 铺层之间的积胶空隙 | 中 | 中 | CF-UD 三角条填充 (3.2 节); 真空辅助确保树脂渗透 |
| 端面不平 → 法兰偏载 | 低 | 高 | 端面加工 (CNC 铣平) + 平面度检查 |
