> **文档版本**: v1.0

> **关联文档**: `S1223_Root_Connection_Design.md`, `S1223_Hub_Design.md`, `S1223_Blade_Structural_Design_Final.md`

## 一、接口总览

```
   Blade 1          Blade 2
      │                 │
      ├── IF-01 ──┐ ┌── IF-01
      │           │ │
      └───────────┼─┼───────────┘
                  │ │
            ┌─────┴─┴─────┐
            │    Hub       │
            │  (上半+下半)  │
            └──────┬───────┘
                   │
                   ├── IF-02 (主轴)
                   │
                   ├── IF-03 (电机法兰)
                   │
                   ▼
                 电机/主轴
```

| 接口编号 | 界面 | 类型 |
|---|---|---|
| **IF-01** | Blade ↔ Hub | 螺栓连接 (12×M16 T-bolt, 预紧力) |
| **IF-02** | Hub ↔ Shaft | 轴孔 + 键连接 (Ø50 H7 + 平键) |
| **IF-03** | Hub ↔ Motor Flange | 螺栓连接 (4×M12, 盲孔) |
| **IF-04** | Hub Upper ↔ Lower | 面接触 (Y=0 分割面) + 4×M12 夹紧螺栓 |

## 二、IF-01: Blade ↔ Hub

### 2.1 几何接口

| 参数 | 值 | 公差 | 归属方 |
|---|---|---|---|
| 叶片根径 (外径) | Φ262 mm | −0.1/+0 | Blade |
| 轮毂内径 | Φ262 mm | +0.1/−0 | Hub |
| 配合类型 | 间隙配合 (滑动装入) | 间隙 0–0.2 mm | — |
| 叶片端面位置 | Y=0 (分割面) | ±0.05 mm | Blade |
| 轮毂分割面位置 | Y=0 | ±0.05 mm | Hub |

### 2.2 螺栓接口

| 参数 | 值 | 归属方 |
|---|---|---|
| 螺栓规格 | M16×1.5, ISO 898-1 10.9 | Hub 提供螺柱 |
| 数量 / 布置 | 12 颗, 均布 PCD=210 (±0.1) mm | 双方一致 |
| 螺柱旋入深度 | 45 ±2 mm (从叶片端面) | Blade (螺栓套内) |
| 螺栓套端面 | 凸出叶片端面 0.5 ±0.2 mm (B 形式) | Blade |
| 预紧力 | 100 ±5 kN / 颗 | 装配方 |
| 拧紧扭矩 | 240 ±10 N·m (MoS₂ 润滑) | 装配方 |
| 拧紧顺序 | 3 阶段对角交叉 | 装配方 |

### 2.3 螺栓孔位置度

```
        12 孔均布于 PCD=210, 起始角 0° (从 +X 轴):

        孔编号    角度        X (mm)     Z (mm)
        B01       0°        105.00       0.00
        B02      30°         90.93      52.50
        B03      60°         52.50      90.93
        B04      90°          0.00     105.00
        B05     120°        −52.50      90.93
        B06     150°        −90.93      52.50
        B07     180°       −105.00       0.00
        B08     210°        −90.93     −52.50
        B09     240°        −52.50     −90.93
        B10     270°          0.00    −105.00
        B11     300°         52.50     −90.93
        B12     330°         90.93     −52.50
```

| 公差项 | 值 |
|---|---|
| 各孔位置度 (相对理论位置) | Φ0.5 mm |
| PCD 直径公差 | 210 ±0.1 mm |
| 相邻孔角度公差 | 30° ±0.1° |
| 孔轴线与 Y 轴平行度 | 0.05 mm / 100 mm |

### 2.4 电偶腐蚀防护 (全碳方案特有)

| 措施 | 归属方 |
|---|---|
| 螺栓套表面镀锌 (8–12 μm) | Blade (螺栓套供应商) |
| GF-VEIL 表面毡 0.1mm 铺设在 CFRP 与钢螺栓套之间 | Blade |
| 装配时螺栓套外表面涂环氧底胶 | Blade |

## 三、IF-02: Hub ↔ 主轴 (Shaft)

### 3.1 轴孔接口

| 参数 | 值 | 公差 | 归属方 | 状态 |
|---|---|---|---|---|
| 轴径 | Ø50 mm | h6 (−0.016/0) | Shaft | ⏳ **占位值** |
| 毂孔径 | Ø50 mm | H7 (+0.025/0) | Hub | ⏳ |
| 配合类型 | 间隙配合 H7/h6 | 间隙 0–0.041 mm | — | |
| 孔深 | 70 mm (贯穿两半) | — | Hub | |
| 旋转轴同轴度 | — | Φ0.02 mm | Hub ↔ Shaft | |

### 3.2 键槽接口

| 参数 | 值 | 标准 | 归属方 | 状态 |
|---|---|---|---|---|
| 类型 | 平键 (Parallel Key) | DIN 6885 | — | |
| 键宽 | 14 mm | JS9 (±0.021) | Hub + Shaft | ⏳ 基于 Ø50 |
| 键高 | 9 mm | h9 | Key | ⏳ |
| 毂槽深 | 3.8 mm (+0.2/0) | — | Hub | ⏳ |
| 轴槽深 | 5.5 mm (+0.2/0) | — | Shaft | ⏳ |
| 键长 | 60 mm | — | Hub (下半圆柱) | |
| 键材料 | C45E (1.1191) | — | Key | |

> ⚠️ **IF-02 全部为占位值**。轴径 50mm 和键 14×9 基于通用机械设计惯例推导。**必须由传动团队确认最终轴径和键规格后更新**。
