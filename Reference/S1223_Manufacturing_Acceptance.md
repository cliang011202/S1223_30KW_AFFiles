# S1223 30kW 叶片 — 制造验收标准 (Manufacturing Acceptance Criteria)

> **文档版本**: v1.0
> **日期**: 2026-05-26
> **用途**: 叶片制造过程中各工序的质量验收门槛
> **依据**: IEC 61400-5:2016, DNVGL-ST-0376:2015, WEH §7.1.12, 王同光 Ch2

---

## 一、原材料入厂检验

| 物料 | 检验项 | 方法 | 频率 | 验收准则 |
|---|---|---|---|---|
| CF-UD-P 拉挤板 | 厚度 | 千分尺 (每板 5 点) | 每批次首件 + 每 50 板 1 件 | 2.00 ±0.06 mm; 2.50 ±0.08 mm |
| CF-UD-P 拉挤板 | 纤维体积分数 | ASTM D3171 (燃烧法) | 每批次 3 件 | Vf ≥ 58% |
| CF-UD-P 拉挤板 | 目视检查 | 目视 + 强光灯 | 100% | 无干纤维、无富树脂区、无分层、无污染 |
| CF-BX 双轴布 | 面密度 | 电子天平 (100×100mm 样) | 每卷 3 件 | 200 ±10 gsm |
| CF-BX 双轴布 | ±45° 角度 | 量角器 (投影仪) | 每卷 3 件 | 45° ±2° |
| CF-BX 双轴布 | 目视检查 | 展开全宽目视 | 每卷 | 无断纱、无跳纱、无污染 |
| PVC 泡沫 | 密度 | ASTM D1622 | 每批次 3 件 | 80 ±8 kg/m³ |
| 环氧树脂 | 粘度 (混合后) | Brookfield 粘度计 @ 25°C | 每批次 | 符合供应商 TDS ±10% |
| 环氧树脂 | 凝胶时间 | 拉丝法 @ 25°C | 每批次 | 符合 TDS ±20% |

## 二、铺层过程检验

| 工序 | 检验项 | 验收准则 | 工具 |
|---|---|---|---|
| 模具准备 | 脱模剂涂覆 | 均匀覆盖，无漏涂 | 目视 + UV 灯 (荧光脱模剂) |
| 蒙皮铺层 | CF-BX 层数 | 每半壳 2 层，无遗漏 | 铺层计数卡 |
| 蒙皮铺层 | 纤维方向 | ±45° (±2°) | 量角器 |
| 蒙皮铺层 | 褶皱 | 前缘曲率区: 无皱褶; 平面区: 皱褶高度 ≤ 0.5mm | 目视 + 塞尺 |
| 主梁铺放 | 拉挤板位置 | 弦向位置 ±2mm (相对 30% chord 基准线) | 模具标线 + 钢板尺 |
| 主梁铺放 | 拉挤板层数 | 按铺层图, 无遗漏 | 计数卡 |
| 主梁铺放 | 板间胶膜 | 每层间 1 张胶膜, 全覆盖 | 目视 |
| 夹芯铺放 | 位置 | 弦向 ±3mm, 展向 ±5mm | 模具标线 |
| 夹芯铺放 | 芯材刻槽 | 槽深 ≥ 2mm (对 3mm PVC), 槽距 30mm | 目视 |
| 叶根螺栓套 | 定位 | 12 颗, 位置度 Φ0.5mm | 定位夹具 + CMM (首件) |
| 叶根 GF-VEIL | 覆盖 | r=0→0.3m 全周长, 无破损 | 目视 |
| 真空袋密封 | 真空检漏 | 抽至 −0.85 bar, 关闭泵 15min 后压降 ≤ 0.02 bar | 真空表 |

## 三、灌注与固化

| 检验项 | 验收准则 | 方法 |
|---|---|---|
| 灌注前真空度 | ≤ −0.9 bar (绝对 ≤ 0.1 bar) | 真空表 |
| 树脂注入量 | 理论量 ±5% (称重) | 电子秤 |
| 灌注速度 | 树脂流动前沿均匀推进, 无短路 | 目视 (透明真空袋) |
| 固化温度 | 按树脂体系 TDS (±3°C) | 热电偶 × 3 (根/中/尖) |
| 固化时间 | ≥ TDS 要求 (温度积分法) | 数据记录仪 |
| 后固化 | 按树脂体系要求 (如 60°C/8h) | 烘箱温度记录 |
| 冷却 | 自然冷却至 ≤ 40°C 后脱模 | 红外测温 |

---

## 四、脱模后检验

| 检验项 | 方法 | 验收准则 |
|---|---|---|
| 外观 | 目视 (强光灯, 500 lux) | 无干斑 (>Φ10mm), 无气泡 (>Φ3mm), 无分层, 无可见裂纹 |
| 色差 | 目视 | 均匀深灰色/黑色 (CFRP 特征), 无白化区 |
| 前缘轮廓 | 轮廓样板 (r=0.68, 1.5, 2.5, 3.5m 各 1 截面) | 偏差 ≤ 0.5mm |
| 尾缘厚度 | 卡尺 (同上截面) | 相比 CAD 模型偏差 ≤ 0.3mm |
| 表面粗糙度 | 触针式粗糙度仪 | Ra ≤ 3.2 (气动面); Ra ≤ 6.3 (叶根圆柱段) |
| 超声检测 | C-扫描 (脉冲回波, 5 MHz) | 主梁区: 无 >Φ10mm 脱粘; 蒙皮夹芯区: 无 >Φ20mm 脱粘 |

---

## 五、合模前检验 (半壳)

| 检验项 | 验收准则 |
|---|---|
| 腹板胶接面清洁度 | 无脱模剂残留, 无粉尘 (白布擦拭测试) |
| 腹板位置 | 30% chord ±3mm (展向 5 截面) |
| 腹板胶黏剂涂覆 | 连续, 无断胶, 胶条宽度 ≥ 50mm |
| 前缘/尾缘胶接带 | 搭接宽度 ≥ 30mm (LE), ≥ 20mm (TE) |

---

## 六、合模后检验

| 检验项 | 方法 | 验收准则 |
|---|---|---|
| 重量 | 电子吊秤 (精度 ±0.05 kg) | **≤ 13.0 kg** (目标 12.5 kg, 上限 +4%) |
| 展向质心 | 两点悬挂法 | 距叶根 1.2 ±0.1 m |
| 弦向质心 | 滚动法 | 弦向位置 30% ±5% chord |
| 固有频率 (1st flap) | 锤击法 (加速度计 @ 叶尖) | 5.3 ±0.5 Hz |
| 固有频率 (1st edge) | 锤击法 | 7.5 ±1.0 Hz |
| 胶接缝外观 | 目视 | 连续胶线, 无空隙 >10mm |
| 胶接缝强度 (试样) | 随炉试样搭接剪切 | ≥ 5 MPa (结构胶特征值 7 MPa / 1.4) |

---

## 七、LEP / 防雷 / 涂装

| 检验项 | 验收准则 |
|---|---|
| 绝缘胶衣厚度 | 0.2 ±0.05 mm (涡流测厚仪, 每 0.5m 展向一点) |
| 胶衣覆盖率 | 100% (无漏涂), 高压火花检漏 (5 kV) |
| LEP 防护罩贴合 | 连续接触, 无空隙 >2mm, 边缘胶封完整 |
| 接闪器安装 | M8 螺纹拧紧 (扭矩 15 ±2 N·m), 导通 ≤ 0.1 Ω (微欧计) |
| 引下线导通 | ≤ 0.5 Ω (接闪器 → 接地环) |
| 均压环导通 | 每个 ≤ 0.2 Ω (环 → 引下线) |

---

## 八、最终验收

| 检验项 | 验收准则 | 方法 |
|---|---|---|
| 总重 | **≤ 13.0 kg** (含 LEP + 防雷 + 胶衣) | 电子吊秤 |
| f₁_flap | 5.3 ±0.5 Hz | 锤击法 |
| 叶根端面平面度 | 0.2mm / Φ262mm | 刀口尺 + 塞尺 |
| 螺栓孔位置度 | Φ0.5mm (12 孔) | CMM |
| 外观最终 | 无缺陷 | 目视 100% 检查 |
| 标识 | Blade 编号 + 制造日期 + 重量 + f₁ 值 | 激光打标 / 铭牌 × 2 (叶根内表面 + 外表面) |

---

## 九、不合格品处置

| 缺陷等级 | 示例 | 处置 |
|---|---|---|
| **A (拒收)** | 主梁区分层 >Φ20mm, 重量 >13.5 kg, f₁ 偏差 >1 Hz | 报废或工程评审 |
| **B (返修)** | 蒙皮表面气泡 >Φ3mm, 胶衣局部漏涂, 螺栓孔轻微偏差 | 返修后重检 |
| **C (让步)** | 表面色差, 标识缺失, 非关键尺寸偏差 <2× 公差 | 记录 + 工程批准 |
