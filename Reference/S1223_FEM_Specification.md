## 一、模型范围与坐标系

### 1.1 建模范围

| 组件 | 是否建模 | 建模方式 |
|---|---|---|
| 叶片气动壳体 (r=0.20→3.50) | ✅ | 壳单元 (Shell), 基于 CAD 曲面 |
| 主梁 (Spar Cap, PS+SS) | ✅ | 壳单元, 叠加到壳体上 |
| 腹板 (Shear Web) | ✅ | 壳单元, 胶接到 PS/SS 壳体 |
| LE/TE 夹芯 | ✅ | 壳单元, 分层截面 (含芯材) |
| 叶根加强层 | ✅ | 壳单元, 局部加厚 |
| 桨柄段 (S0, r=0→0.20) | ✅ | 壳/体单元 (近实心截面) |
| 轮毂 | ❌ | 等效为边界条件 (固支) |
| 叶根螺栓 | ❌ | 等效为 RBE2 刚性约束 |
| LEP / 绝缘胶衣 | ❌ | 不计入刚度 (仅计质量) |

### 1.2 坐标系

| 轴 | 方向 | 对应 |
|---|---|---|
| Y | 展向, root→tip | 旋转轴方向 |
| X | 挥舞方向 | 转子平面法向 (推力方向) |
| Z | 弦向 | 大致平行于 chord line |

```
     Tip (Y=3.5m)
       ↑ Y
       │
   ┌───┼───┐
   │   │   │
   │   │   │  ← 叶片表面 (壳单元)
   │   │   │
   └───┼───┘
       │
       ↓ Y=0 (Root, 固支)
```

## 二、单元选择与网格

### 2.1 单元类型

| 软件 | 推荐单元 | 备选 | 说明 |
|---|---|---|---|
| ANSYS | SHELL181 (4-node, 6 DOF) | SHELL281 (8-node) | 大变形 + 复合材料截面 |
| ABAQUS | S4R (4-node, reduced integration) | S8R (8-node) | S4R 为默认选择 |
| Nastran | CQUAD4 | CTRIA3 (过渡区 <5%) | — |

### 2.2 网格密度

| 方向 | 单元尺寸 | 说明 |
|---|---|---|
| **展向 (Y)** | 50 mm | 14 站 → 约 70 行单元 (3.5m / 50mm) |
| **弦向 (前缘→尾缘)** | **10 mm** | 翼型周长 ~0.6m (最大弦长) → 约 60 列单元 |
| 展向 (局部加密) | 25 mm | r=1.0→2.0m (翼型过渡段, 应力梯度大) |
| 弦向 (局部加密) | 5 mm | 主梁区域、LE/TE 加强区 |

**目标总单元数**: ~5,000–10,000 (4-node 壳), 网格收敛性验证 ±3% 应力变化。

### 2.3 网格质量要求

| 指标 | 限值 |
|---|---|
| 长宽比 (Aspect Ratio) | ≤ 5 |
| 翘曲角 (Warping) | ≤ 15° |
| 内角 (Interior Angle) | 45°–135° |
| 雅可比 (Jacobian) | ≥ 0.6 |
| 三角形单元占比 | ≤ 5% (仅过渡区) |

## 三、复合材料截面定义

### 3.1 材料属性

| 材料 | E₁ (GPa) | E₂ (GPa) | G₁₂ (GPa) | ν₁₂ | ρ (kg/m³) | 来源 |
|---|---|---|---|---|---|---|
| CF-UD-P (0° 拉挤板) | **141** | 9.0 | 4.5 | 0.30 | 1550 | WEH 表 7.1 #3 |
| CF-BX (±45° 双轴布) | **40** | 40 | **25** | 0.35 | 1550 | 等效 ±45° CFRP |
| PVC80 芯材 | 0.10 | 0.10 | 0.03 | 0.30 | 80 | 表 2-6 |
| 结构胶 | 3.0 | 3.0 | 1.2 | 0.35 | 1200 | — |

> **CF-BX 等效性能推导**: ±45° CFRP 层合板的等效 E_x 和 G_xy 通过 CLT 从 UD 单层 (E₁=141, E₂=9.0, G₁₂=4.5, ν₁₂=0.30) 旋转 ±45° 叠加得到。E_x(±45°) ≈ 40 GPa, G_xy(±45°) ≈ 25 GPa。此为初步估算值，正式分析前应做 ±45° CFRP 试样实测 (ASTM D3518 ±45° 拉伸剪切测 G₁₂)。
>
> **CF-UD-P 横向性能**: E₂ 和 G₁₂ 由基体主导，取环氧树脂典型值。

### 3.2 失效准则

| 分析类型 | 准则 | 适用材料 |
|---|---|---|
| ULS | **Tsai-Wu** (二次交互) | CFRP UD, CFRP ±45° |
| ULS | **最大应力** (校核参考) | CFRP UD |
| 芯材 | **von Mises** | PVC 泡沫 |
| 胶层 | **最大剪应力** (τ ≤ 7 MPa) | 结构胶 |
| 屈曲 | **线性特征值屈曲** (Eigenvalue Buckling) | 全体 |
| 疲劳 | **Palmgren-Miner** + 线性 Goodman | CFRP (m=14) |

### 3.3 截面分层定义

展向分为 5 个截面区 (zone)，每区定义铺层序列。详见 `S1223_Blade_Layup_Book.md` §4。

**典型截面 (S1 DU 段, idx 2) — 弦向分区**:

```
        LE面板          主梁          TE面板
     (前缘→主梁)    (弦向~30%)   (主梁尾缘→尾缘)
    ┌──────┬─────────────────┬──────────┐
    │ PVC  │  CF-UD-P2 × 2   │  PVC     │  ← 芯材/主梁
    │ 3mm  │  (拉挤碳板)      │  3mm     │
    ├──────┼─────────────────┼──────────┤
    │        CF-BX × 2 (0.50mm)          │  ← 蒙皮 (全场)
    └───────────────────────────────────┘

    截面分层序列 (从外到内):
    L1: CF-BX / ±45° / 0.25mm   (全场)
    L2: CF-BX / ±45° / 0.25mm   (全场)
    [主梁段附加]:
    L3: CF-UD-P / 0° / 2.0mm    (拉挤板 #1)
    L4: CF-UD-P / 0° / 2.0mm    (拉挤板 #2)
    L5: CF-BX / ±45° / 0.25mm   (内蒙皮, 覆盖主梁)
    [LE/TE 夹芯段附加]:
    LC: PVC80 / 3.0mm            (芯材)
```

## 四、边界条件

### 4.1 静态/屈曲分析

| 位置 | 约束 | 说明 |
|---|---|---|
| 叶根端面 (r=0.20m, Y=0 面) | **全固支** (UX=UY=UZ=RX=RY=RZ=0) | 等效于轮毂刚性约束 |
| 或: 螺栓位置 | 12 个 RBE2 刚性单元连接至中心点 → 固支中心点 | 更精确 (推荐) |

```
    推荐方案 (RBE2):
    
        12 个螺栓位置节点 (PCD=210) ← RBE2 从属节点
              │
              ├── RBE2 主节点 @ Y=0, X=Z=0
              │
              └── 固支主节点: UX=UY=UZ=RX=RY=RZ=0
```

### 4.2 模态分析

仅释放绕 Y 轴旋转 (RY) — 叶片绕旋转轴自由。其余 5 个 DOF 约束。

### 4.3 疲劳分析

同静态分析 (全固支或 RBE2+固支)。

## 五、载荷施加

### 5.1 载荷来源

所有载荷来自 `S1223_Load_Envelope.md`。

### 5.2 ULS 静强度分析

施加叶根弯矩 M_xB=14.6 kN·m 和 M_yB=3.1 kN·m 作为**力矩**，施加于 RBE2 主节点。

或使用**多点约束载荷分布**方法：沿展向在 5 个截面上施加与力矩分布一致的法向力。

### 5.3 挠度分析

施加特征弯矩 M_xB=9.83 kN·m (无安全系数) → 提取叶尖 Y 向位移。

### 5.4 屈曲分析

施加特征弯矩 × γ_f (=1.35) → M_xB=9.83×1.35=13.3 kN·m → 提取第一阶正特征值 λ₁。验收: λ₁ ≥ 1.0。

### 5.5 模态分析

无外力。仅重力场 (9.81 m/s², −X 方向) 作为预应力。

### 5.6 疲劳分析

施加 DLC A 疲劳载荷 (ΔM_xB=3.9 kN·m, ΔM_yB=0.22 kN·m) → 提取主梁 SS 和 TE 的应力变程 → Palmgren-Miner 累积损伤。

| # | 分析类型 | 求解器 | 载荷 | 输出 | 验收准则 |
|---|---|---|---|---|---|
| 1 | **线性静力** | Static | M_xB=14.6 kN·m | Tsai-Wu FI ≤ 1.0 | 所有单元 FI < 0.95 |
| 2 | **线性静力** | Static | M_yB=3.1 kN·m | Tsai-Wu FI | FI < 0.95 |

## 七、后处理要求

### 7.1 云图输出

| 输出量 | 云图范围 | 说明 |
|---|---|---|
| Tsai-Wu Failure Index | Full blade, PS + SS | FI 峰值位置标记 |
| 纤维方向应力 σ₁₁ (0° 方向) | 主梁区 | 对比 σ_cd=619 MPa |
| 面内剪应力 τ₁₂ | 蒙皮区 (TE 面板) | 芯材剪切 |
| U-displacement (Y 方向) | Full blade | 挠度 |
| Buckling mode shape (λ₁) | Full blade | 屈曲模态 |

### 7.2 关键位置应力提取

| 位置 | 展向 r (m) | 弦向 | 提取分量 |
|---|---|---|---|
| 主梁 SS, 最大弯矩处 | ~1.5 (SG6050) | 主梁中心 | σ₁₁ (纤维方向) |
| 主梁 SS, 翼型过渡处 | ~1.14 (DU→SG) | 主梁中心 | σ₁₁ |
| TE 面板 | ~1.5 | 尾缘夹芯中点 | τ₁₂ (芯材剪切) |
| LE 面板 | ~1.5 | 前缘夹芯中点 | σ₁₁ |
| 叶根螺栓孔 | ~0.2 | 各孔周围 | Tsai-Wu FI (子模型) |

### 7.3 网格收敛性

对同一工况 (推荐分析 #1) 以 2× 单元密度 (展向 25mm, 弦向 5mm) 重复计算。关键输出 (σ₁₁_max, U_tip, λ₁) 变化 ≤ 3%。
