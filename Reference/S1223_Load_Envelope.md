## 一、坐标系与符号约定

### 1.1 叶根坐标系 (IEC 61400-2:2013)

```
        旋转轴 (Y)
           ↑
           │
      ┌────┼────┐
      │    │    │
      │    │    │  Blade
      │    │    │
      └────┼────┘
           │
    ───────┼───────→ X_B (挥舞, 推力方向 = 转子平面法向)
           │
          Z_B (展向, root → tip)
          (出纸面)
```

| 分量 | 方向 | 物理意义 | 主导载荷源 |
|---|---|---|---|
| **F_xB** | 挥舞剪力 | 推力在叶根的剪力 | 气动推力 |
| **F_yB** | 摆振剪力 | 转子平面内剪力 | 扭矩反力 + 重力 |
| **F_zB** | 轴向力 | 沿叶片展向 (+ = 离心拉力) | 离心力 |
| **M_xB** | 挥舞弯矩 | 叶片出平面弯曲 | 气动推力 |
| **M_yB** | 摆振弯矩 | 叶片面内弯曲 | 扭矩 + 重力 |
| **M_zB** | 叶根扭转 | 叶片绕展轴扭转 | 气动俯仰力矩 |

### 1.2 符号正负约定

- F_zB: **+** = 离心拉力 (叶片被向外拉); **−** = 压缩
- M_xB: **+** = 使叶片向下风方向弯曲 (吸力面受拉)
- M_yB: **+** = 使叶片向尾缘方向弯曲

## 三、设计载荷工况 (DLC)

### 3.1 DLC A — 正常运行疲劳

| 分量 | 范围 (peak-to-peak) | 说明 |
|---|---|---|
| F_zB | 245.3 N | 重力分量翻转 (2×12.5×9.81) |
| M_xB | 3881 N·m | 挥舞 1P 振幅 (偏航误差+风剪, ±30% 均值) |
| M_yB | **294 N·m** | **摆振重力翻转 (主导疲劳)** 2×m_B×g×R_cog = 2×12.5×9.81×1.2 |

> **主导疲劳机理**: 每转一次的重力翻转在摆振方向产生 ΔM_yB=294 N·m（vs 旧值 220 N·m, +34% 因质量增加）。碳纤维 m=14 的 S-N 斜率使疲劳裕度仍然充裕。

### 3.2 DLC D — 极端推力 (极阵风)

| 分量 | 值 | 设计值 (×γ=1.485) | 说明 |
|---|---|---|---|
| F_xB | 4158 N | **6175 N** | 阵风推力 / B |
| F_yB | 273 N | 1218 N | 扭矩反力 |
| F_zB | 25207 N | 37432 N | 离心 (Ω_design, m_B=12.5 kg) |
| **M_xB** | **9849 N·m** | **14626 N·m** | **挥舞 (控制 ULS)** |
| M_yB | 780 N·m | 1158 N·m | 摆振 (扭矩+重力) |
| M_zB | 36.7 N·m | 54.5 N·m | 气动俯仰 |

> **控制工况**: M_xB=14.6 kN·m 是叶片主梁设计的控制载荷。

### 3.3 DLC E — 最大转速 (超速 1.25×Ω)

| 分量 | 值 | 设计值 (×γ=1.485) | 说明 |
|---|---|---|---|
| **F_zB** | **39398 N** | **58506 N** | **离心 (控制轴向)** |
| F_xB | 2772 N | 4116 N | 稳态推力 |
| M_xB | 6468 N·m | 9605 N·m | 挥舞 |
| M_yB | 670 N·m | 995 N·m | 摆振 |

> **控制工况**: F_zB=58.5 kN 是叶根螺栓设计的控制载荷（vs 旧值 43.7 kN, +34%）。12×M16 10.9 级螺栓利用率仍仅 20%。

### 3.4 DLC G — 发电机短路制动

| 分量 | 值 | 设计值 (×γ=1.485) | 说明 |
|---|---|---|---|
| F_yB | 820 N | **1218 N** | 制动扭矩反力 |

| F_zB | 25207 N | 37432 N | 离心 (m_B=12.5) |

> **控制工况**: M_yB=3.2 kN·m 是摆振方向的最大载荷（vs 旧值 3.1 kN·m, +1.7%）。

### 3.5 DLC H — 停机极端风 (50-yr, 含涵道屏蔽)

| 分量 | 值 | 设计值 (×γ=1.485) | 说明 |

## 五、载荷在 FEM 中的应用

### 5.1 加载点

所有载荷施加于叶根截面 (r=0.2m)，坐标系原点位于旋转轴与叶根截面的交点。

### 5.2 弯矩沿展向分布

对初步 FEM 分析，特征值 M_xB 沿展向的分布近似为（设计文档 §4.3）：

$$M_{xB}(r) = M_{xB,root} \times (1 - r/R)^2$$

| r/R | M_xB / M_xB_root | M_xB,char (kN·m) | M_xB,des (kN·m) |
|---|---|---|---|
| 0.0 (root) | 1.00 | 9.81 | 14.57 |
| 0.2 | 0.64 | 6.28 | 9.33 |
| 0.4 | 0.36 | 3.53 | 5.25 |
| 0.6 | 0.16 | 1.57 | 2.33 |
| 0.8 | 0.04 | 0.39 | 0.58 |
| 1.0 (tip) | 0 | 0 | 0 |

### 5.3 载荷组合

FEM 分析中的载荷组合遵循 IEC 61400-2 §7.4：

| 分析类型 | 载荷组合 | 安全系数 |
|---|---|---|
| ULS 静强度 | D_load = D_char × γ_f·γ_m | 1.485 |
| 疲劳 | D_fatigue_range × γ_f_fat·γ_m_fat | 1.25 |
| 挠度 | D_char (无安全系数) | 1.0 |
| 屈曲 | D_char × γ_f | 1.35 |
| 模态 | 无载荷 (仅质量+刚度) | N/A |
| 频率避开 | 无载荷 | N/A |
